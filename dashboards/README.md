# Dashboards

Future dashboards should begin with descriptive pathway and data-quality measures, such as:

- Case and specimen volumes
- Specimen-to-receipt and receipt-to-result durations
- Missing-event and incomplete-pathway rates
- Invalid and repeat-run counts
- Result communication and acknowledgement completeness

Thresholds must not be invented in code. Any target or alert boundary must have a documented,
approved source and an owner.
